# Rock-Paper-Scissors Mind Reader (Project) 

People are poor random-number generators, so their next Rock-Paper-Scissors move usually depends on the moves before it. This project builds a learning, model-based agent for the AL-2002 AI Lab (Fall 2026, FAST-NUCES Karachi, Idea 08). The agent watches its opponent's moves, models them with a **frequency model**, **order-1 and order-2 Markov chains** and a **Hidden Markov Model whose hidden state is the player's strategy**, predicts the next move and plays the move with the highest expected utility. You can play it in a Streamlit app and watch its win rate climb above the 1/3 you'd expect by chance. A seeded experiment script compares all the predictors against five scripted bots and against each other in a round-robin tournament.

## Run

| What | Command |
|---|---|
| Play the game (Streamlit app) | `streamlit run src/app.py` |
| Reproduce every result and chart | `python src/experiment.py --seed 42` |
| Fast smoke run (10 games × 100 rounds) | `python src/experiment.py --quick` |
| Run the tests | `python -m pytest` |

`experiment.py` uses every CPU core by default (`--jobs N` to change it). The full run takes about 2 minutes on an 8-core laptop. Each game is seeded independently, so **the numbers are the same for any `--jobs` value**. Results go to `outputs/results/` (CSV and Markdown) and figures to `outputs/figures/`.

## Features

- **Play vs AI**: the AI commits to its move before reading yours. It shows a live win-rate chart against the 1/3 chance line, its forecast of your next move, the Markov transition table, and the HMM's belief, transition matrix and emission matrix.
- **Bot vs Bot**: pit any predictor against any scripted bot or another predictor. Against the Switching bot, it plots the HMM's belief next to the bot's true hidden strategy.
- **Tournament**: shows the saved results table, round-robin heatmap and figures, or runs a small tournament live.
- **Predictors**: Random (baseline), Frequency, Markov-1, Markov-2, Markov-1J (order-1 with the whole last round as context), and HMM (hmmlearn Baum-Welch with our own NumPy forward filter).
- **Opponent bots**: Random, Biased (50/30/20), Cyclic (R→P→S, 10% noise), Win-Stay/Lose-Shift (10% noise), and Switching. Switching secretly favours one move (80%) and changes strategy with probability 0.05 each round.
- **Live parameters**: Markov smoothing α and memory decay; HMM number of states K and refit interval.

## Results (seed 42, 100 games × 200 rounds per pairing)

AI win rate in %, mean ± std (chance = 33.3):

| Predictor | Random | Biased | Cyclic | WSLS | Switching | Mean |
|---|---|---|---|---|---|---|
| Random | 33.6 ± 3.3 | 33.3 ± 3.3 | 33.1 ± 3.3 | 33.6 ± 3.2 | 33.7 ± 3.3 | 33.5 |
| Frequency | 32.8 ± 3.4 | **49.1** ± 4.1 | 24.8 ± 5.6 | 30.0 ± 1.7 | 44.1 ± 7.8 | 36.1 |
| Markov-1 | 33.3 ± 3.5 | 47.1 ± 4.3 | **85.7** ± 2.9 | 31.4 ± 5.3 | 60.4 ± 5.5 | 51.6 |
| Markov-2 | 32.9 ± 3.3 | 43.6 ± 4.1 | 83.7 ± 3.1 | 47.5 ± 12.9 | **60.6** ± 5.3 | 53.7 |
| Markov-1J | 33.2 ± 3.3 | 45.5 ± 4.5 | 83.4 ± 3.2 | **89.9** ± 2.2 | 57.7 ± 5.9 | **61.9** |
| HMM | 33.2 ± 3.2 | 46.4 ± 5.0 | 79.3 ± 2.9 | 47.9 ± 19.8 | 60.2 ± 6.1 | 53.4 |

Against the Switching bot, the HMM's filtered belief identifies the true hidden strategy in **93%** of rounds, compared with 88.5% for the raw 10-round move counts. Its learned transition matrix has a diagonal of about 0.96–0.98, close to the true 0.95. The figures are in `outputs/figures/`: win rate by bot, learning curves, tournament heatmap, HMM belief, Markov transition tables, and the HMM K-ablation.

## Data

There is no external dataset. All opponent data are generated by the seeded bots in `src/bots.py`: game *i* uses seed `42 + i` for the bot and `42 + i + 10000` for the AI, so every predictor faces identical move streams. The app's optional CSV download contains only move choices.

## Known limitations

- Against a truly random opponent no predictor can beat 1/3. That is the Random column, and it's expected.
- Markov models over the opponent's own moves can't see players who react to the AI's moves (WSLS). Markov-1J fixes this by including the AI's move in the context.
- Higher-order models need more data. Markov-2 has 9 contexts and learns more slowly than Markov-1.
- The HMM's state labels are arbitrary and can permute between refits. Baum-Welch only finds a local optimum, which we mitigate with random restarts plus a warm start. Fitting costs more than counting, so it refits every 10 rounds.
- A deterministic predictor can itself be predicted. In the tournament, the HMM loses to the Markov agents.
- Only the bots are tested systematically. Human-play results depend on the player.
